## About This Repository

**Django Engineering Journey** documents my hands-on journey from Django fundamentals to building maintainable, production-oriented web applications.

This repository focuses on understanding how web applications work internally, writing code independently, solving practical problems, and applying engineering principles through real projects.

Rather than simply following tutorials, the goal is to learn concepts, implement them, debug issues, and improve solutions through practice.

## Engineering Goals

- Build a strong foundation in Python and Django.
- Understand Django's MVT architecture and request-response lifecycle.
- Integrate MySQL with Django applications.
- Build complete CRUD applications and reusable components.
- Learn authentication, authorization, validation, and security.
- Write readable, maintainable, and testable code.
- Progress toward deployment and production-oriented engineering.

## Engineering Principles

- Readability over unnecessary complexity.
- Understand the code instead of blindly copying it.
- Validate inputs and handle errors intentionally.
- Never commit passwords, API keys, or secrets.
- Use Git to track meaningful changes.
- Document setup instructions for reproducibility.
- Treat testing and security as essential parts of development.

## Getting Started

To create a fresh Django project locally:

```bash
python3 -m venv .venv
source .venv/bin/activate

python -m pip install django

django-admin startproject config .
python manage.py check
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

**Note:** These commands are for a fresh starter project, not for an existing Django project. Follow the relevant project's setup instructions and install its dependencies. Configure MySQL separately for projects that use it.
